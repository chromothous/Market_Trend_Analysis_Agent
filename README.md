# Market Trend Analysis Agent

An AI powered workflow built during the **Extern Wayfair AI Automation Externship** that automates market research by collecting, analyzing, and summarizing industry trends into actionable business intelligence reports. The agent helps identify emerging opportunities, consumer preferences, and market shifts to support data driven decision making.

---

## 🛠️ Technologies

* n8n
* Open Router and Mistrel AI
* AI Prompt Engineering
* REST APIs
* Web Data Collection
* HTML Report Generation
* Data Transformation
* Business Intelligence Automation

---

## ✨ Features

* Automatically gathers market trend data
* Analyzes consumer and industry trends
* Summarizes findings using AI
* Generates structured market analysis reports
* Produces business ready insights
* Designed as a modular workflow for future expansion

---

## 🔄 Process

1. User selects a product category.
2. The workflow gathers relevant market information from online sources.
3. Data is cleaned and organized for AI processing.
4. Open Router and Mistrel analyzes the collected information.
5. The AI generates a comprehensive market trend report.
6. The report is formatted into an organized HTML document for review and future workflows.

## ▶️ Running the Project

### Prerequisites

* n8n installed or hosted
* Open Router and Mistrel API credentials
* Internet connection for data collection
* Required API credentials configured within n8n

### Steps

1. Import the workflow into n8n.
2. Configure all required credentials.
3. Enter the desired product category.
4. Execute the workflow.
5. Review the generated HTML market analysis report.
